# DSA Lab 2 – Sorting Techniques

## 1. Problem Statement
To implement different sorting algorithms in C++ to arrange elements in ascending or descending order.

## 2. Approach
Implemented the following sorting algorithms:
- **Bubble Sort:** Repeatedly compares and swaps adjacent elements.
- **Insertion Sort:** Places each element in its correct position.
- **Selection Sort:** Selects the smallest element and places it in the correct position.
- **Quick Sort:** Uses a pivot to divide elements into smaller and larger groups.

## 3. Time and Space Complexity

| Algorithm | Average Time | Space |
|---|---|---|
| Bubble Sort | O(n²) | O(1) |
| Insertion Sort | O(n²) | O(1) |
| Selection Sort | O(n²) | O(1) |
| Quick Sort | O(n log n) | O(log n) |

## 4. Sample Input / Output

**Input:**
```text
5 2 8 1 3
```

**Output:**
```text
1 2 3 5 8
```
