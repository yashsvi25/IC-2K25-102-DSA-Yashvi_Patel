# DSA Lab – Stack

## 1. Problem Statement
To implement a Stack using C++ and perform basic stack operations following the LIFO (Last In, First Out) principle.

## 2. Approach
Implemented the following stack operations:
- **Push:** Inserts an element into the stack.
- **Pop:** Removes the top element.
- **Peek:** Displays the top element.
- **Display:** Shows all stack elements.
- **isEmpty:** Checks whether the stack is empty.
- **isFull:** Checks whether the stack is full.

## 3. Time and Space Complexity

| Operation | Time Complexity |
|---|---|
| Push | O(1) |
| Pop | O(1) |
| Peek | O(1) |
| Display | O(n) |
| Search | O(n) |

**Space Complexity:** O(n), where n is the maximum stack capacity.

## 4. Sample Input / Output

**Input:**
```text
Push: 10
Push: 20
Push: 30
Pop
```

**Output:**
```text
Stack: 10 20
Top Element: 20
```
