# DSA Lab – Merge Sort and Radix Sort

## 1. Problem Statement
To implement Merge Sort and Radix Sort in C++ to arrange elements in ascending order efficiently.

## 2. Approach

- **Merge Sort:** Divides the array into smaller parts, sorts them recursively and merges them into a sorted array.
- **Radix Sort:** Sorts numbers digit by digit, starting from the least significant digit.

## 3. Time and Space Complexity

| Algorithm | Time Complexity | Space Complexity |
|---|---|---|
| Merge Sort | O(n log n) | O(n) |
| Radix Sort | O(d × (n + k)) | O(n + k) |

Where:
- n = Number of elements
- d = Number of digits in the largest number
- k = Range of digits (0–9)

## 4. Sample Input / Output

**Input:**
```text
38 12 27 43 9 31
```

**Output:**
```text
9 12 27 31 38 43
```
