# DSA Lab 6 – Arrays and Matrix Operations

## 1. Problem Statement
To implement basic array and matrix operations using C++ and understand their practical applications.

## 2. Approach
Implemented the following programs:
- **1D Array:** Performs basic operations on one-dimensional arrays.
- **Matrix Calculator:** Performs arithmetic operations on matrices.
- **Sparse Matrix:** Represents a matrix containing mostly zero elements in an efficient way.

## 3. Time and Space Complexity

| Operation | Time Complexity |
|---|---|
| Array Traversal | O(n) |
| Matrix Addition | O(r × c) |
| Matrix Multiplication | O(r × c × k) |
| Sparse Matrix Representation | Depends on non-zero elements |

## 4. Sample Input / Output

**Sample Input:**
```text
Array: 10 20 30 40 50
```

**Sample Output:**
```text
Array Elements:
10 20 30 40 50
```
