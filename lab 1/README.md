# DSA Lab 1 – Searching Techniques

## 1. Problem Statement
To implement different searching techniques in C++ to find a given element in a collection of data.

## 2. Approach
Implemented the following searching algorithms:
- **Linear Search:** Checks each element one by one.
- **Binary Search:** Searches by repeatedly dividing sorted data into halves.
- **Index Sequential Search:** Uses an index to locate elements efficiently.

## 3. Time and Space Complexity

| Algorithm | Time Complexity | Space Complexity |
|---|---|---|
| Linear Search | O(n) | O(1) |
| Binary Search | O(log n) | O(1) |
| Index Sequential Search | Depends on indexing | Depends on implementation |

## 4. Sample Input / Output

**Sample Input:**
```text
Array: 10 20 30 40 50
Element to search: 30
```

**Sample Output:**
```text
Element found at position 3
```
